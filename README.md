# whip_rope

A physics rope. Players carry it as an item, tie it to cars, props and the ground where they aim, tow with it, and
hang off it. whip_fuel's pump hose is a whip_rope rope too.

- **Needs:** whip_core.
- **Install:** WHIP's txAdmin recipe installs it and adds `ensure whip_rope` to server.cfg. Nothing else to add, no SQL.
- **Settings:** `/whip` → Settings → Rope (length, how many pieces, what the rope bumps into). Or `config.lua`.
- **Docs:** whip_core's docs, the whip_rope group: Rope System (using it, settings, debug commands), Learning from
  rope (the parts of this code worth reading), and Rope Exports (make a rope between two things from your own script).
